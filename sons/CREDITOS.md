# Créditos dos sons

As gravações dos instrumentos nesta pasta vêm do **FluidR3_GM**, de Frank Wen,
convertidas para MP3 pelo projeto
[midi-js-soundfonts](https://github.com/gleitz/midi-js-soundfonts), de Benjamin Gleitzman.

Licença: [Creative Commons Attribution 3.0](https://creativecommons.org/licenses/by/3.0/).

Os arquivos são baixados por `scripts/baixar-sons.mjs`. O app mostra este
crédito na tela inicial, como a licença exige.
